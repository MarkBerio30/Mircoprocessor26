# GarbDetect: Automated Wet and Dry Garbage Detection with IoT-based User Notification
 - This system focuses on the development of an automated garbage detection system using IoT-based sensors that can distinguish between wet and dry garbage. The system will incorporate a user notification feature to send alerts to the user when the garbage bin is full and needs to be emptied. The proposed project will emphasize the development of both hardware and software components. The hardware components will include moisture sensors, microcontrollers, and other electronic components required to detect the moisture level in the garbage. The software component will involve developing an algorithm to classify the garbage as wet or dry and a user notification feature to send alerts to the user's smartphone or other electronic devices. Additionally, an ESP32 module will be integrated to enable image classification for wet and dry garbage. The image classification model, trained using Teachable Machine, will be deployed on the ESP32 to detect and classify garbage based on captured images.
# Hardware Tools Used:
  - Arduino Uno r3 board
  - MG90S Servo
  - 2pcs Ultrasonic Sensor
  - Sim800L GSM Module
  - 12V Power Adapter
  - 2pcs LED
  - Jumper Wire
  - Moisture Sensor
  - Teachable Machine (Train Image)
  - Esp32 Cam
  - Buzzer
  - Breadboard
  - I2C LCD Display
  - IR Sensor
# How it Works
- Put Dry or Wet Garbage it will read the IR Sensor or Moisture if garbage is wet or dry. ESP32Cam to detect and classify garbage based on captured images.
